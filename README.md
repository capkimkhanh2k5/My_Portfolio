## 🚀 Getting Started

Want to run this locally? Follow these simple steps:

### Prerequisites
*   **Node.js** (v18+)
*   **npm** or **yarn**

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/capkimkhanh2k5/Portfolio.git
    cd Portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Explore**
    Open [http://localhost:3000](http://localhost:3000) in your browser.
