## 📖 About The Project

Welcome to my personal portfolio repository. This project is a testament to my journey as a developer, showcasing not just my technical skills but my passion for creating immersive, high-performance digital experiences. It seamlessly blends solid back-end logic with a stunning, interactive front-end.

This isn't just a showcase; it's a playground where I experiment with the latest technologies, push the boundaries of web performance, and demonstrate my ability to build full-stack applications that are both functional and beautiful.

## 🚀 Getting Started

Want to run this locally? Follow these simple steps to get up and running.

### Prerequisites
*   **Node.js** (v18+)
*   **npm** or **yarn**

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/capkimkhanh2k5/Portfolio.git
    cd Portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Explore**
    Open [http://localhost:3000](http://localhost:3000) in your browser.
